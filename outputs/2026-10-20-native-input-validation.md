# 原生输入组件与微信流程验收

环境：vivo X21 / Android 9 / 微信 8.0.79 / 官方 AutoJs6 6.7.0。
验收跨 2026-10-20 至 2026-10-21。
本轮发送类流程均为预演，没有点击发送，未验证消息实际送达。

## 已确认

- 原生输入组件采用 Kotlin InputMethodService 和受校验的本地 ContentProvider；无网络权限、无截图或 OCR。优化并签名后的 APK 为 29,360 字节。调用方仅限已授权 ADB shell、组件自身和固定官方证书的 AutoJs6。
- 原生中文搜索、输入 1、完整回读、拒绝覆盖已有草稿、只清理本轮相同草稿均已通过。系统键盘选择器通过原生标签和行边界定位，无模型参与；切换并恢复日常键盘的闭环通过。
- 手机真实商店与 Cron 快照入口：打开微信、读取昵称、首个会话通过；文件传输助手完整预演通过，执行后原键盘恢复。页面导航使用用户指定的图像模型；文字值由原生接口回读。
- 批量流程已完整枚举当前 12 个群；按空白、全角括号与竖线变体规范化去重后，12 个群均已完成输入、回读和清理。结果累计来自手机脚本 v30、v31、v35、v36，并非最新版一次连续全量跑完。语音模式会先独立核对底部输入栏，再切回文字模式。
- 定位并修复前台判断问题：AutoJs6 的事件缓存包名可能属于输入法，实际焦点应用仍是微信；运行器改读系统窗口信息，模态窗口阻止继续操作。
- 顶部入口由原生窗口尺寸确定，模型只确认局部工具栏，页面切换只重新观察、不重放点击；不再依赖整页模型坐标或粘贴菜单。
- 手机脚本 v37：群选择入口必须具有完整且唯一的已知标签；缺失、错读、重复或不完整时最多重新读取三次，不把「创建新群聊」当作入口。此校验与桌面端同步。
- 返回首页优先点击已确认的应用内返回按钮；此前使用系统返回时触发了前台保护，调整后手机实际 Cron 流程复测通过，桌面同步采用相同规则。没有放宽前台检查。
- 手机真实分钟 Cron 已触发并完成「打开微信」；前置 GET 提取 JSON 字段，结束 POST 校验 Bearer、查询参数与成功状态。任务使用固定代码及配置快照，结束后停用本轮验收任务，没有正式发送。
- 桌面视觉流程在原生连接已确认目标输入类型且内容为空时直接使用现有焦点，不重复点击；保留页面、会话、前台与已有文字校验。回归测试会拒绝多余点击，并验证原生框中已有文字时不覆盖。
- 本轮手机控制器 39 项测试、桌面视觉逻辑 11 项测试通过，覆盖误读入口、应用内返回、原生焦点、已有草稿保护和千会话逻辑。Windows 交叉构建移除与 Tauri 冲突的强制静态 CRT 参数后，链接与 NSIS 打包已通过。
- 桌面最新执行器的打开微信、读取昵称、首个会话、文件传输助手预演、指定群聊批量预演五条真机流程均通过；批量累计 3 个群通过，其中最后一次连续完成剩余 2 群。每群都有回读、清理和逐会话结果，没有发送事件；每轮唤醒设置与日常键盘均恢复。
- 已重建包含本轮修复的 0.3.6 本地验收包：`deliverables/PorAuto_0.3.6_macos-apple-silicon.dmg` 与 `deliverables/PorAuto_0.3.6_windows-x86_64-setup.exe`。Mac 包内 ADB 平台及摘要已校验；手机离线工作流为微信 v37 / 企业微信 v21。

## 边界

Windows 尚未在 Windows 系统实际安装运行；本地验收包未生成自动更新签名，正式发布仍需既有私钥，尚未发布。桌面批量只验收了上述 3 个群；手机的 12 群为跨版本累计结果。千会话逻辑测试不代表千群真机性能验收。正式发送及网络送达未测试。

配置、脚本、每会话结果与错误证据均保存在本机；验收截图与实际会话名称不提交到仓库。

本机交叉构建补装了 Homebrew LLVM 23.1.3_2，同时升级其 z3 依赖；未修改项目依赖。构建资源缓存最终恢复为 macOS。
