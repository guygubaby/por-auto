## 已修复的实际问题

1. 接收设置只保留单聊 / 群聊分类，支持同时勾选；去除名称填写、逐个勾选与读取选择列表的界面和额外请求。新分类合并去重，旧配置首次编辑默认预演，原定时快照不自动扩大范围。
2. 运行记录、接收对象结果和日志原先全部渲染。现在每页 50 条，历史页码写入 URL，搜索重置页码；日志展开时才创建内容。跨页选择保留，导出仍遵循后端 100 条上限。没有筛选结果时提供清除筛选操作。
3. 截图使用延迟加载和异步解码，限制在内容宽度内，减少记录详情的图片解码与窄屏溢出。
4. 旧目录中的 `visual-*.png` 曾被当作诊断文字读入 JSON 导出；现在只包含 XML、日志和视觉 JSON / TXT，避免损坏诊断文本或无谓放大导出。
5. 键盘恢复曾在 ADB 掉线时提前清除恢复状态；现在只有确认恢复或用户自行换键盘后才清除状态，并在恢复前最多等待设备重连 5 秒。故障注入覆盖读取失败、设置失败、恢复未生效及用户换键盘，已通过 Go 竞态检查。
6. 图像接口独立支持 HTTP / HTTPS 与 5–600 秒超时，不改变业务 HTTP 请求的地址和 120 秒上限。超时明确报错，输入和发送不自动重放。
