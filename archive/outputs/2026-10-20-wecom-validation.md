# 企业微信原生工作流验收

环境：vivo X21 / Android 9 / 企业微信 5.0.8 / 官方 AutoJs6 6.7.0。
本轮所有发送类测试均为**预演**，没有点击发送，没有验证网络送达。

## 已验证

- 电脑：Rust + uiautomator2 原生读取。打开消息首页、读取当前姓名、打开首个普通会话、当前全部群聊批量预演，四个工作流通过。当前账号只有一个可枚举群聊。
- 手机：手机商店的 `manager.runPinned` 真实入口，使用固定脚本和配置快照执行同样四个流程。最新一次四个流程均通过，批量消息 `Ok` 原生写入、完整回读、清理；没有调用图像模型或截图授权。
- 手机真实 Cron：保存启用的五段 Cron，等待到下一分钟后由 `tick()` 触发，记录触发类型为 `cron`，执行完成后关闭该测试任务。
- 同轮 HTTP：前置 POST → 进入并核对群聊 → 消息 GET → 结束 POST。验证 Bearer 鉴权、查询参数、请求头、上下文变量、`/data/message` JSON 提取与结束状态。测试接口只返回 `Ok`，没有发送消息。
- 原生提示：电脑连接组件增加 `isShowingHintText()` 标志，手机直接读取 Android 原生标志。区分空输入框提示语和与提示语内容相同的真实草稿，后者保留。
- 大列表定位：原生搜索栏 + 群聊分类 + 完整名称结果 + 打开后核对标题；没有匹配时才回到完整列表查找。单元测试覆盖搜索分类、单次打开和空页面只观察不重放点击。
- 手机打包：共享代码生成到可被 GitHub 直接读取的实际路径；每个发布文件可校验大小和散列。共享代码变更须同时增加微信/企业微信包的 `versionCode`。

## 验收边界

- 一千会话的顺序、持久化、HTTP 新鲜度由自动测试验证；当前真机没有一千个群，未声称完成一千群真机性能验收。
- 微信 8.0.79 的空原生控件与手机视觉输入粘贴菜单问题仍需继续解决；企业微信通过不代表微信也已全部通过。
- 操作应保持手机解锁，应用和手机版本变化需重新验证控件兼容性；系统停止 AutoJs6 后需重新开启服务与定时会话。
- 0.3.4 为新的试用构建；尚未发布正式 GitHub Release 或替换稳定更新源。
