# Por Auto · 使用说明

适用于 Windows 10/11 64 位电脑与 Android 手机。

## 首次使用

1. 下载 Windows 安装包，双击安装程序，按提示完成安装。
2. 打开软件，点击「初始化连接组件」，等待完成。
3. 手机开启「USB 调试」，用数据线连接电脑并允许调试；保持手机解锁、微信已登录。
4. 点击「刷新设备」，勾选手机；先运行「打开微信」，再运行「读取微信昵称」，到「运行结果」核对。
5. 在「工作流商店」找到需要的工作流，点击「配置」。填写消息或设置内容接口，选择仅群聊或聊天会话，再勾选接收对象，也可以选择全部。

新安装的发送工作流默认开启「演练模式」：进入会话、填写核对文字，再清理本轮草稿，不点击微信发送。先确认演练结果，再按需要关闭演练，进行正式运行。文件传输助手示例的内容固定为「1」。

## 页面无法读取时

若手机提示微信页面控件无法读取，先在「模型设置」填写开发者提供的接口地址、模型和密钥，点击「测试连接」并保存；允许截图后，在对应工作流的「配置」中选择「视觉 AI」。

视觉模式需要连接所选模型接口；中文输入需要手机已安装官方 AutoJs6，无需开启它的无障碍服务。原生模式无需模型。运行期间请暂时不要操作手机。

## 设置内容与时间

- 消息可以手动填写，也可以从内容接口获取。接口配置支持参数、鉴权、请求测试和响应解析；可选每轮获取一次，或每个会话前获取最新内容。
- 如需在开始前获取数据、结束后回传结果，可配置「运行前」「运行后」接口；演练时这些接口也会执行。
- 在「定时任务」新建任务，选择工作流和手机，设置时间并预览接下来的执行时间。可先点「立即执行」检查流程。
- 修改工作流配置后，已有定时任务需编辑并更新快照，才会采用新配置，包括演练开关。

保持软件运行、电脑唤醒和手机连接；最小化窗口仍可执行。退出或休眠错过的时间不补跑，上一轮未结束时跳过本轮；同一手机的任务排队。发送结果不明时会停止，请先核对手机记录再决定是否重新运行。

## 工作流、记录和更新

「工作流商店」可安装、更新或卸载工作流；卸载会暂停关联定时任务并保留日志。添加私有来源时，填写有仓库读取权限的令牌，仅用于本次同步。

「运行记录」可查看逐步日志及各会话结果。勾选记录后可批量导出 JSON 发给开发者，也可批量清理；删除前请先导出需要保留的记录。

点击右上角版本号可检查软件更新。已正式发布的新版可下载安装并重启；试用包尚未发布到正式更新源时，需要手动安装。更新保留本机配置、定时任务与记录。

部分 Windows 手机需要品牌官方 USB 驱动；手机无法识别时可查看右上角「环境诊断」。不同手机与微信界面需要分别验证，页面出现验证提示时软件会停止。
