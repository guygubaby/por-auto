# Por Auto · 工作流试用版

适用环境：Windows 10/11 64 位电脑 + Android 手机。所选工作流的应用与语言要求见工作流说明。

以下以随软件附带的「读取微信昵称」为例验证连接流程。

## 试用流程

1. 运行同目录的 `Por Auto` EXE 安装包，按提示完成安装。若电脑缺少 WebView2，安装器会联网下载安装。
2. 打开软件，点击「初始化连接组件」。Android 连接工具已随软件附带，无须自行安装 Python 或配置命令行。
3. 手机开启「开发者选项 → USB 调试」，用支持传输数据的 USB 线连接电脑。在手机上点击「允许 USB 调试」。
4. 解锁手机并登录微信，回到微信主界面。在「设备与运行」点击「刷新设备」，勾选一台或多台已授权手机，也可以全选。
5. 选择工作流「读取微信昵称」，点击「运行工作流」，等待完成。在「运行结果」选择对应手机，核对昵称、手机截图与手机「我 → 个人信息」页是否一致。手机最多同时执行 4 台，同一手机任务排队，一台失败会继续其他手机。

0.2.4 支持新版微信的「个人资料 → 名字」页面。部分微信版本无法提供页面控件，昵称示例会改用电脑本机截图识别；结果会标明读取方式，请结合截图核对，尤其是表情和特殊字符。Windows 如提示缺少文字识别语言功能，请在系统语言设置中安装简体中文的 OCR 功能。

读取期间不要手动切换手机页面。部分 Windows 电脑需先安装手机品牌的官方 USB 驱动；软件中有连接排查指引。

## 获取新工作流

软件内打开「工作流商店」，默认选中官方来源。选择来源卡片查看工作流；添加其他来源时点击右上角「添加 Registry」。公开仓库可直接同步；私有仓库需填写有该仓库访问权限、Contents 只读权限的 GitHub 令牌，然后安装或更新需要的工作流。令牌只用于这次同步，提交后清空。

安装完成后回到「设备与运行」，在工作流列表选择并运行。已安装工作流、源列表、定时任务和运行结果均保存在本机，安装后可离线运行。获取新工作流时需要联网。

## 结果与反馈

读取成功后显示真实昵称和本次手机截图。失败时显示原因，并尽可能保留页面截图与结构；点击「打开结果目录」查看 `result.json`、`screen.png`、`hierarchy.xml`。

若未成功，请反馈电脑系统、手机型号、Android 版本、微信版本、失败提示及本次截图。可以只提供必要信息，截图中的无关信息可遮挡。

本版附带的昵称示例用于验证连接和读取流程。支持多手机顺序执行及定时调度，工作流能力以商店说明为准。不同微信界面仍需通过实际手机验证。本试用包未购买商业代码签名证书，Windows 可能显示未知发布者提示。

## 查看日志、导出与清理

侧栏「运行记录」保存每次执行的步骤时间、完成状态与错误。点击「查看日志」可以看到具体失败位置。勾选一条或多条记录，点击「导出 JSON」，选择保存位置，即可将文件发给开发者排查问题。

「删除所选」或「清空记录」会再次确认，并同时清理这些记录的截图和页面结构；有需要时请先导出。

## 配置定时任务

1. 在侧栏打开「定时任务」，点击「新建定时任务」。
2. 填写任务名称，选择工作流和手机。时区默认本机；中国内地通常使用 `Asia/Shanghai`。
3. 选择快捷时间，或填写五段 Cron。例如 `0 9 * * *` 为每天 09:00，`0 9 * * 1-5` 为工作日 09:00，`*/30 * * * *` 为每半小时。点击「校验并预览」核对未来 5 次执行时间，再保存。
4. 可先点击「立即执行」验证流程，再保持任务启用。任务卡片显示下次时间、上次状态，支持编辑、暂停、删除和查看日志。
5. 从任务卡片点击「运行日志」，可查看该任务的批次与手机记录，勾选后导出 JSON。删除任务会保留已有日志。

保持客户端运行、电脑唤醒和手机连接。最小化窗口后仍会调度；退出客户端或休眠错过的时间不会补跑。上一轮未完成、或其他任务占用执行器时跳过本轮，并记录原因。暂停后当前批次仍会完成；手机失败后不会自动重试。

保存任务时固定工作流版本，商店更新不会自动改变已有任务。需要新版本时，先在商店更新，再编辑任务并勾选更新快照。验证分钟触发可临时使用 `* * * * *`，验收后改回正式频率。

## 更新软件

点击右上角版本号打开「软件更新」。默认启动时及每 6 小时检查 GitHub Release，也可以手动「检查更新」或关闭自动检查。发现新版本后可查看更新说明，点击「下载更新并重启」完成更新；请等待正在执行的工作流结束。更新保留本机配置、已安装工作流、定时任务和日志。

下载需要能连接 GitHub。下载或签名校验失败时显示错误，当前版本仍可使用，可稍后重试。0.1.0 旧试用版需先手动安装带更新器的新版本，此后即可在应用内更新。


0.2.1 新增测试：先选一台手机运行「打开微信首个会话」，核对名称与截图；再选「向首个会话发送你好」，点击「运行并发送」。该操作会真实发出「你好」，第一个会话包含置顶。已有草稿会停止，结果不明时先查看手机，避免直接重跑重复发送。
