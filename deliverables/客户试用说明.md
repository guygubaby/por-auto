# Por Auto · 使用说明

适用于 Windows 10/11 64 位电脑与 Android 手机。

当前只支持企业微信，不支持普通微信的读取或发送。本文描述当前源码行为；已有安装包不一定包含最新修复，版本和验收边界见 [修复记录](../outputs/2026-10-22-review-fixes.md)。

## 首次使用

1. 下载 Windows 安装包，双击安装程序，按提示完成安装。
2. 打开软件，点击「初始化连接组件」，等待完成。
3. 手机开启「USB 调试」，用数据线连接电脑并允许调试；保持手机解锁、企业微信已登录。
4. 点击「刷新设备」，勾选手机；先运行「打开企业微信」，再运行「读取企业微信姓名」，到「运行结果」核对。
5. 在「工作流商店」找到需要的工作流，点击「配置」。填写消息或设置内容接口，勾选「单聊」「群聊」或同时勾选，运行时自动读取所选类型的全部对象，无需填写或选择名称。

新安装的发送工作流默认开启「演练模式」：进入会话、填写核对文字，再清理本轮草稿，不点击企业微信发送。先确认演练结果，再按需要关闭演练，进行正式运行。

## 页面无法读取时

软件只通过系统无障碍控件读取页面，不截图、不使用图像模型。若提示企业微信没有返回可用控件，软件会安全停止；请保持手机解锁后重试，并把对应运行记录导出给开发者核对机型与企业微信版本。

名称被省略、数字前缀不同、同名或消息方向无法核对时，不会猜测目标或自动重发。结果中的“已观察”只表示发送端原生界面出现对应消息，不保证其他成员已经收到。

## 设置内容与时间

- 消息可以手动填写，也可以从内容接口获取。接口配置支持参数、鉴权、请求测试和响应解析；可选每轮获取一次，或每个会话前获取最新内容。
- 如需在开始前获取数据、结束后回传结果，可配置「运行前」「运行后」接口；演练时这些接口也会执行。
- 在「定时任务」新建任务，选择工作流和手机，设置时间并预览接下来的执行时间。可先点「立即执行」检查流程。
- 修改工作流配置后，已有定时任务需编辑并更新快照，才会采用新配置，包括演练开关。

保持软件运行、电脑唤醒和手机连接；最小化窗口仍可执行。退出或休眠错过的时间不补跑，上一轮未结束时跳过本轮；同一手机的任务排队。发送结果不明时会停止，请先核对手机记录再决定是否重新运行。

## 工作流、记录和更新

「工作流商店」可安装、更新或卸载工作流；卸载会暂停关联定时任务并保留日志。添加私有来源时，填写有仓库读取权限的令牌，仅用于本次同步。

卸载后，关联旧任务不能启用或立即执行；需先重新安装工作流。正在运行的定时批次结束前不能卸载。独立手机包更新到 `1.0.12 / 58` 后，原配置与凭据保留，但手机旧定时任务需重新创建才能使用修复后的脚本。

「运行记录」可查看逐步日志及各会话结果。勾选记录后可批量导出 JSON 发给开发者，也可批量清理；删除前请先导出需要保留的记录。

在「设置 → 软件更新」检查软件更新。已正式发布的新版可下载安装并重启；试用包尚未发布到正式更新源时，需要手动安装。更新保留本机配置、定时任务与记录。

部分 Windows 手机需要品牌官方 USB 驱动；手机无法识别时可在工作台刷新设备状态。不同手机与企业微信版本需要分别验证，页面出现验证提示时软件会停止。

## 外观主题

顶部主题菜单和「设置 → 外观」支持浅色、深色和跟随系统，选择会保存；跟随系统时自动响应电脑的外观变化。

0.4.x 使用新的 MyGo 客户端，旧版用户需要手动安装一次；仍沿用本机工作流、定时任务、凭据引用和运行记录。
